# Artfolio

### A full-stack social media platform for artists.

<HeroImage image={artfolio_cover} title="Artfolio" />

This is a full-stack monorepo application, with client done in **Vue** using **TypeScript**, and server set up with **Node.js** and **Express**.

<br />

**Better Auth** is used for authentication, with **Redis** caching the sessions. Emails are sent by Mailjet. Site is styled with Tailwind, and can be used on a variety of devices thanks to the responsive design.

<br />

**PostgreSQL** is used as this project's database, with **Drizzle** as its ORM. Zod ensures data validation, while **tRPC** is implemented for end-to-end type safety. **Playwright** covers E2E testing, with **Vitest** used for unit tests. Docker sets up local postgres and redis containers.

<br />

Application data is stored in Neon database. Upstash Redis is used for production Redis caching. Client is deployed on Vercel, while the server is hosted by Render.
